# Owl Skips inventory assets

Public Steam Inventory Service icons for App **5327880**: 54 collectible cards,
27 Common and 27 Rare. All 108 PNGs retain the approved export bytes.

[Download ItemDefs.json](https://raw.githubusercontent.com/fdddfdfs/owl-skips-inventory-assets/main/ItemDefs.json) · [Image manifest](https://raw.githubusercontent.com/fdddfdfs/owl-skips-inventory-assets/main/manifest.json)

Small icons are 200×200; large images are 2048×2048. The schema preserves the
90% Common / 10% Rare playtime generator. Trading is enabled and Market sales
remain disabled pending Valve approval. These items provide no gameplay bonuses.

Keep existing versioned image paths available for Steam downloads. Changed
artwork should receive a new path and corresponding schema URLs.
